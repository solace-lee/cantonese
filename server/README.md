# 服务端边界

前端的自由对话直接请求配置好的 OpenAI 兼容模型接口，服务端不保存具体对话资源，也不负责拼装学习内容。服务端只负责用户身份、年龄段偏好和基础设置。

建议提供以下最小接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/auth/login` | 登录并返回用户资料；可用账号密码、家庭邀请码或第三方登录适配 |
| `POST` | `/api/auth/logout` | 清理服务端会话 |
| `GET` | `/api/me` | 获取当前用户资料 |
| `PATCH` | `/api/me` | 更新昵称、年龄段、语言偏好和头像 |

`src/lib/userClient.ts` 已按这个边界封装。模型配置和对话上下文留在浏览器/模型接口侧；生产环境可以把模型请求改为同源代理，以避免浏览器跨域和暴露 API Key。

年龄段使用 `3-6`、`6-12`、`12-plus` 三个值，前端的 `src/lib/ageProfiles.ts` 负责提示词与交互参数。服务端只保存用户当前选中的 `ageGroup`，不保存课程内容。

仓库还附带了一个不依赖第三方包的本地用户服务示例：

```bash
npm run server:dev
```

它监听 `http://localhost:8787`，提供上述四个路由、内存用户和 HttpOnly 会话 Cookie，仅用于本地联调。可用 `CLIENT_ORIGIN` 设置允许的前端来源。生产环境应替换为真实数据库、密码哈希、会话存储和日志审计。
