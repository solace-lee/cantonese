# Canto芽 · 儿童粤语学习

这是一个 React + Vite + TypeScript 的儿童粤语学习站，采用 **SVG 主渲染 + Canvas 2D 粒子层**。默认按开源 BYOK 模式运行：用户在浏览器配置自己的模型 API，项目不强制依赖服务端。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

换机交接、当前限制与后续开发计划见 [docs/roadmap.md](./docs/roadmap.md)。

## 已实现

- 四套可切换的 SVG 学习场景：蓝天草地、欢乐球场、荷花池塘、玩具房间
- 卡通角色的闭嘴 / a / i / u 嘴型状态，播放时随节奏切换
- Web Speech API 发音播放（优先使用设备的 `zh-HK` 音色），支持朗读模型回复
- Canvas 2D 漂浮粒子层
- 选择场景、点击“生成新场景”或对话明确转到新地点时，请模型设计场景；未配置接口或生成失败时使用内置模板
- OpenAI 兼容接口设置：Base URL、模型、API Key、系统提示词
- “小麦”自由对话：上下文由前端维护，配置 API 后通过 `ChatClient` 请求 `/chat/completions`；自定义服务可连接无密钥代理；请求携带最近 20 条消息
- API 配置保存在当前浏览器的 `localStorage`
- 年龄段模式：3–6 岁、6–12 岁、12+，分别切换提示词、文案和交互密度
- 大屏模式：放大场景与按钮，适配电视和远距离观看
- `src/lib/userClient.ts` 是可选用户服务客户端，目前未接入页面；服务端不保存对话资源
- 模型可以返回受约束的 `SceneSpec` JSON，前端用白名单 SVG renderer 生成场景；无效或超时会回退到内置模板
- `server/` 是可选的用户服务/代理示例，不是前端运行的必需依赖

对话内容会发送到所配置的模型服务，当前对话只存在页面内存中；切换年龄段或关闭页面会清空。生成的场景按服务、模型、年龄段和主题缓存在 IndexedDB，按钮可清空对话及场景缓存。请勿在对话中填写儿童真实姓名、学校、住址或联系方式。

浏览器的 API Key 保存在 `localStorage`，同一浏览器中的脚本和有设备访问权的人可能读取它。自定义接口需要允许浏览器跨域访问（CORS）；公开部署或共享密钥时应使用自行部署、带访问控制的代理。接口配置和隐私细节见 [docs/providers.md](./docs/providers.md)。

服务端接口边界与建议路由见 [server/README.md](./server/README.md)。

可选用户服务目前仅提供客户端封装和本地服务示例，尚未接入页面登录和偏好同步。模型对话直接走 `ChatClient`。


口型目前在播放时按固定节奏近似变化，并非与语音音素精确同步；准确同步需要提供音素或 viseme 时间信息的语音服务。浏览器未安装粤语音色时会尝试默认语音，发音效果取决于设备。

当前不提供语音识别，也没有学习进度统计、账户登录或偏好同步功能。
