# 模型接口配置

网站可以作为静态前端部署，由家长配置自己的 OpenAI 兼容模型接口，不需要服务端管理对话内容。设置中的 Base URL 指向接口根地址，例如 `https://api.example.com/v1`；客户端会向其追加 `/chat/completions`，使用配置的模型名称发送请求。请确认所选服务支持浏览器跨域（CORS）访问。

API Key 会随请求发送给所配置的服务提供商。默认情况下，Key 只保留在当前页面的内存中；用户主动勾选“在这台设备保存 API Key”后，Key 才会随接口配置写入 `localStorage`。使用同一浏览器的其他人或有权限运行的脚本可能读取已保存的 Key。建议使用单独的、设有额度限制的密钥，不要在公共设备上保存，并避免将密钥或儿童对话记录提交到代码仓库。设置中的“清除配置”会移除已保存的接口配置和 Key。浏览器直连时，也请了解所选服务商对对话数据的处理方式。

需要隐藏共享密钥或解决跨域时，可以自行部署受控的 OpenAI 兼容代理，将 Base URL 指向该代理。代理与浏览器之间的认证、访问限制、用量控制及日志保留由部署者负责；建议默认不记录儿童对话内容。底层客户端在 API Key 为空时不会发送 Authorization 请求头，代理也可以采用自己的认证方式。

对话请求通过提示词要求模型返回 `reply`、可选 `ttsText`、`lessonHint`，以及用于迁景的 `sceneTheme`、`sceneBrief` 和 `sceneTags`；客户端也兼容纯文本回复。场景摘要会限长并清除常见链接、邮箱和长数字串，但不保证模型一定不会生成其他个人信息，因此缓存键只使用由摘要和受控标签生成的稳定签名。场景请求使用清洗后的摘要，另行生成受约束的 `sceneSpec`。目前支持蓝天草地、球场、池塘和玩具房四种主题。

设置中的“测试连接”会发送一条很短的测试请求，可能产生少量模型用量。客户端会区分请求超时、取消、配置错误、鉴权失败、网络/CORS、频率限制和响应解析失败；浏览器不能可靠区分普通网络中断与 CORS 拒绝，因此这两类问题会合并提示。`response_format: { "type": "json_object" }` 只在请求显式启用时发送，使用前请确认服务商支持该参数。模型返回的场景数据属于不可信输入，必须交给场景校验器处理，不能作为原始 SVG 或 HTML 注入页面。
